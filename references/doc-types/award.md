# 获奖证书与奖学金（Urkunde / Preis / Stipendium / Award / Scholarship / 获奖证书）

一个奖项本身只是一行字，**奖项背后的项目或过程**才是故事。另外，德国 HR 大多不了解中国的竞赛和奖学金，所以要把奖项的分量讲清楚。

## 分类

| 类别 | 例子 |
|---|---|
| 竞赛 | 数学建模（MCM/ICM、全国大学生数学建模竞赛）、ACM-ICPC、黑客松、创业比赛、Case Competition |
| 奖学金 | Deutschlandstipendium、DAAD、各类基金会奖学金（Studienstiftung 等）、国家奖学金、校级奖学金 |
| 学术荣誉 | 最佳论文、优秀毕业论文、Dean's List、优秀毕业生 |
| 其他 | 志愿服务表彰、体育和艺术奖项 |

## 提取

| 字段 | 说明 |
|---|---|
| 名称 | 原名；有官方英文或德文名称的一并记下 |
| 颁发方 | |
| 级别 | 国际 / 国家 / 省（州）/ 校 |
| 名次和规模 | 例如"一等奖""Meritorious Winner"；参赛人数或队数、获奖比例 |
| 日期 | |
| 个人或团队 | 团队的话，几个人、用户的角色 |
| 获奖的作品或原因 | 什么项目、什么成绩 |

## 讲清分量

德国读者看不懂"省级一等奖"有多难。网站上用一句话说明规模，格式例如（N、P 是占位符，要换成核实过的数字）：

- "全国大学生数学建模竞赛 一等奖（全国 N 支队伍参赛，获奖比例约 P%）"
- "Deutschlandstipendium（按学业成绩和社会参与评选的奖学金）"

规模数字要来自证书、官方页面或用户确认，**不要凭印象写**。不确定就写到用户确认过的程度，例如只写"全国赛，一等奖"。

## 深挖线索

- 竞赛奖项 → 问：做的是什么题目、你负责哪部分、方案有什么特别之处、有没有报告或截图。适合做成故事。
- 奖学金 → 问：评选看什么（成绩、社会参与、研究计划）。可以印证用户的某种特质。
- 奖项和某段经历时间重叠 → 可能是同一个项目，在交叉比对里关联起来

## 网站用途

- 荣誉版块：名称、级别、名次、一句话分量说明
- 有故事的奖项 → 独立故事页，或者作为某个故事的证据
- 文件墙：获奖证书默认公开或只展示摘要

## 敏感信息

获奖证书上的身份证号、学号要遮住；证书上有其他队员的名字时，公开前提醒用户。
