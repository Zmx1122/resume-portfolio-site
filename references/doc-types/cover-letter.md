# 求职信（Anschreiben / Motivationsschreiben / Cover Letter / 个人陈述）

求职信是用户**用自己的话讲自己**的地方。简历给出"做过什么"，求职信透露"为什么做、想去哪、觉得自己强在哪"。它是首页定位语和"关于我"最好的素材。

## 识别

- 德式 Anschreiben：右上角日期和地点，`Betreff: Bewerbung als …`，开头 `Sehr geehrte …`，结尾 `Mit freundlichen Grüßen`
- Motivationsschreiben：多用于申请学校或奖学金，讲动机和学术方向
- 英文 Cover Letter / Statement of Purpose
- 中文求职信、个人陈述

## 提取

| 字段 | 说明 |
|---|---|
| 投递对象 | 公司或学校、岗位名称、日期 |
| 动机 | 为什么是这个领域、这类岗位、这个国家 |
| 自我评价的优势 | 用户自己说的强项，逐条列出 |
| 讲到的事例 | 用来支撑优势的经历或故事，标明对应哪段经历 |
| 简历里没有的信息 | 新的经历、项目、细节、数字 |
| 语气 | 正式 / 热情 / 克制；用户写德语的熟练程度 |

## 多封求职信

把所有求职信放在一起看：

- **反复出现的主题**（比如每封都讲"把数据变成业务决策"）就是用户的核心叙事，首页定位语围绕它写。
- **投递岗位的分布**能看出求职方向，和简历的定位差异一起交给采访模块 A。
- **只出现一次的事例**可能是为某家公司特意挑的，问用户要不要放进网站。

## 深挖线索

- 讲了优势但没给例子 → 交叉比对 5.4，问具体例子
- 提到的事例在简历里只有一行 → 优先挖成故事
- "为什么来德国""为什么转专业"讲得很动人 → "关于我"版块的候选，问用户愿不愿意公开

## 网站用途

- 核心叙事 → 首页定位语、"关于我"
- 事例 → 对应故事页的背景
- 动机 → "关于我"

## 不要做的事

- 不要照搬针对某家公司的句子（"Ihr Unternehmen ist führend in …"）。网站面对所有读者。
- 不要把求职信原件放上网站。
- 求职信里的自我评价是用户的主观说法，进网站前要么有证据，要么改写成事实描述。
