# 毕业论文和学期论文（Bachelorarbeit / Masterarbeit / Studienarbeit / 毕业论文）

对学生和应届生来说，论文通常是**最完整的一段经历**：有问题、有方法、有结果，还常常和企业合作。但用户一般只在简历里写一行题目。所以论文要**主动去要**（见 `best-practice-checklist.md` 的 B 节），拿到后认真提炼。

## 识别

- 完整的论文 PDF：封面有学校、题目、作者、导师，常有"Erklärung"（独立完成声明）
- 摘要页：Abstract、Kurzfassung、Zusammenfassung、摘要
- 结论页：Conclusion、Fazit、Zusammenfassung und Ausblick、结论与展望
- 答辩幻灯片：Kolloquium、Verteidigung、Defense
- 封面后面有 **Sperrvermerk**（保密声明）的：说明论文和企业合作且需要保密，见下面"保密"

整篇论文很长时，**优先读摘要、结论和目录**，再按需要看方法和结果章节，不用通读。

## 提取

| 字段 | 从哪里找 | 说明 |
|---|---|---|
| 题目 | 封面 | 原文照录；网站其他语言的版本，用论文自带的英文或德文题目，没有就翻译并在 `facts.md` 里标"译" |
| 类型和学校 | 封面 | 本科、硕士、学期论文；学校、教席或研究所 |
| 时间 | 封面、Erklärung 的日期 | 写成开始和结束的年月，或者至少写结束的年份。**不要留空，否则网站会显示"至今"** |
| 导师 | 封面 | 只用于事实核对，网站上写不写由用户决定 |
| 合作企业 | 封面、致谢、Sperrvermerk | 有合作企业是加分项，但要先确认能不能公开企业名 |
| 研究问题 | 摘要第一段、引言 | 一两句话：要解决什么问题，为什么重要 |
| 方法 | 摘要中段、方法章节 | 用了什么数据、模型、实验或工具，用用户能在面试里讲清楚的话写 |
| 结果 | 摘要最后、结论 | **优先找带数字的结果**（比如"误差从 19.8% 降到 11.6%"），连同条件一起记（在什么数据上、和什么比） |
| 贡献和意义 | 结论 | 结果对实践或研究有什么用 |
| 最能说明结果的一张图 | 结果章节 | 截图作为故事页配图；图里的数据如果保密，就不用 |
| 成绩 | 成绩单（不是论文本身） | 和 `transcript.md` 一起处理，问用户要不要公开 |

## 提炼成故事

论文提炼成一个故事（`stories`，`kind: "thesis"`，`parent` 指向对应的教育条目）：

- **标题**：用问题或结果起标题，比如"仓库下个月需要多少备件？"或"把预测误差从 19.8% 降到 11.6%"，而不是论文的完整题目
- **问题**：1–2 句，来自摘要第一段
- **我做了什么**：2–4 条，来自方法
- **结果**：1–2 句，来自结论，带数字
- **关键数字**：1–2 个最有分量的结果（`metrics`），来源写这份论文的材料编号
- **配图**：最能说明结果的一张图；有答辩照片的话，照片放第一张
- 论文已经发表的，在 `publications` 里也加上，`story` 指向这个故事

写好后给用户确认，尤其是数字和方法的描述。论文是用户自己写的，TA最清楚哪里写得不准。

## 深挖线索

- "整篇论文里，你最满意的是哪个结果？"
- "如果接着做，你会做什么？"（面试常被问到，可以写进故事的结果部分）
- "论文用到的技能，有哪些是你现在工作或求职时最想强调的？"
- 和企业合作的："企业后来用了你的结果吗？"

## 保密

- **有 Sperrvermerk 的论文**：不要公开论文原件、企业的数据和具体结果。只写研究问题、方法和一句概括的结果（比如"提出的方法明显提高了预测准确度"），企业名问用户能不能写。
- 论文原件默认**不公开**（可按需提供）。用户想公开整篇论文时，确认没有保密限制，再放进 `site/assets/docs/`。
- 论文里的图如果用了企业数据，同样要确认能否公开。
