# 工作证明（Arbeitszeugnis / Praktikumszeugnis / 实习证明）

德国的工作证明是**雇主写的、比简历详细得多的职责清单**，还附带一套约定俗成的委婉评价语。很多留学生拿到后并不完全读得懂。它是资料池里最容易挖出隐藏亮点的材料。

## 识别与分类

| 类型 | 特征 | 价值 |
|---|---|---|
| qualifiziertes Arbeitszeugnis | 有职责描述，也有工作表现和行为评价 | 最高 |
| einfaches Arbeitszeugnis / Arbeitsbescheinigung | 只有职位和起止时间，没有评价 | 只能证明时间和职位 |
| Zwischenzeugnis | 在职期间开具的阶段性证明 | 同 qualifiziert |
| Praktikumszeugnis / Praktikumsbescheinigung | 实习证明，评价语通常没有正式证明那么讲究 | 主要用职责清单 |
| 中文实习证明 / 工作证明 | 通常只有职位、时间和盖章 | 证明时间和职位 |

典型结构：抬头（公司信纸）→ 个人信息和在职时间 → 公司介绍 → **职责描述** → **工作表现评价**（Leistungsbeurteilung）→ **行为评价**（Verhaltensbeurteilung）→ 离职原因 → **结束语**（Schlussformel）→ 签名。

## 提取

| 字段 | 说明 |
|---|---|
| 公司、职位、部门 | 以证明上的正式写法为准 |
| 在职时间 | 精确到日，网站上用到月 |
| 职责清单 | **逐条提取**，这是最有用的部分；和简历要点逐条对照 |
| 提到的项目、系统、工具 | 简历里没写的标出来 |
| 被点名的能力和优点 | 例如 analytisches Denkvermögen、Eigeninitiative、Teamfähigkeit |
| 工作表现评价 | 原文 + 你的解读（见下表） |
| 行为评价 | 原文 + 解读 |
| 离职原因 | 原文 |
| 结束语 | 有没有表示遗憾、感谢、祝福 |
| 签名人 | 职位（部门负责人、HR、总经理） |
| 可引用的句子 | 挑 1–2 句最具体、最正面的 |

## 评价语对照（只供你内部判断）

德国雇主不会在证明里写负面的话，所以评价是用**措辞的强弱**来表达的。下表是业界常用的解读惯例，不是法律规定，也不是每家公司都严格遵守，外资公司和实习证明尤其随意。

**工作表现**

| 常见措辞 | 大致相当于 |
|---|---|
| stets zu unserer vollsten Zufriedenheit | 很好（1） |
| stets zu unserer vollen Zufriedenheit / zu unserer vollsten Zufriedenheit | 好（2） |
| zu unserer vollen Zufriedenheit / stets zu unserer Zufriedenheit | 中等（3） |
| zu unserer Zufriedenheit | 及格（4） |
| im Großen und Ganzen zu unserer Zufriedenheit | 不太好（5） |
| hat sich bemüht … / war bemüht … | 差（6） |

关键词："stets"（始终）和"vollsten"（最充分）越多越好。

**行为评价**：
- "Sein/Ihr Verhalten gegenüber Vorgesetzten, Kollegen und Kunden war **stets vorbildlich**" 大致相当于很好。
- 只写 "einwandfrei" 而没有 "stets" 大致相当于中等。
- 惯例上上级排在同事前面；把同事放在上级前面，有时被解读为和上级相处有问题。

**结束语**：同时包含"遗憾TA离开 + 感谢 + 祝福未来"是很好的信号；缺了遗憾或感谢，评价就弱一些。离职原因写 "auf eigenen Wunsch"（本人意愿）是正常且偏正面的。

### 怎么用这些解读

- **用来挑素材**：评价很好的证明，可以放心引用其中的评价句；评价一般的，只用职责清单，不引用评价句。
- **告诉用户时要分情况**：评价好的，直接告诉TA"这份证明整体评价是'很好'，可以放心引用"，很多人会因此更有信心。评价一般的，只说"这份证明我们主要用它的职责内容"，不要主动给TA打分。用户明确问到时，如实解释，并说明这只是惯例解读。
- **不要把解读出来的分数写上网站。**

## 深挖线索

- 职责清单里有、简历里没有的项目或任务 → 头号隐藏亮点，优先问
- 被点名的能力 → 作为技能的证据，问一个具体例子补成故事
- 证明里提到了数字或范围（"für 3 Abteilungen""ca. 50 Nutzer"）→ 直接用于故事的结果部分
- 职位名称和简历不一致 → 交叉比对的冲突

## 网站用途

- 职责清单 → 故事页"我做了什么"的素材（改写，不照抄）
- 可引用的句子 → 故事页的证据摘录，格式例如："… durch ihre strukturierte und eigenständige Arbeitsweise." —— 摘自 Muster GmbH 工作证明。多语言网站可以放原文加译文
- 文件墙 → 默认"只展示摘要"，原件"可按需提供"

## 敏感信息

证明里通常有出生日期、出生地、住址、签名，原件默认不公开。
