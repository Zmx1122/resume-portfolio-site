# 成绩单与学位证明（Notenspiegel / Transcript of Records / Bachelor- und Masterzeugnis / 学位证 / 毕业证）

成绩单里藏着两样有用的东西：**和目标岗位相关的课程**，以及**毕业论文或项目课**。后者经常能成为一个完整的故事。总成绩要不要展示，由用户决定。

## 识别

- 德国：Notenspiegel、Leistungsübersicht、Transcript of Records（课程、学分、成绩列表）；Bachelorzeugnis、Masterzeugnis（总成绩和论文成绩）；Urkunde（授予学位的证书，通常没有成绩）
- 中国：成绩单（百分制或五级制，常附 GPA）、学位证、毕业证
- 其他国家：按标题和学校判断

## 提取

| 字段 | 说明 |
|---|---|
| 学校、专业、学位 | 正式名称，例如 Master of Science Informatik |
| 时间 | 入学和毕业（或预计毕业） |
| 总成绩 | 原文和原始评分体系 |
| 学分 | 已修 ECTS / 总 ECTS |
| 毕业论文 | 题目、成绩、导师或教席、合作企业（如有） |
| 相关课程 | 和目标岗位相关的课程，附成绩和学分 |
| 研讨课、项目课 | 题目和成绩，可能是故事素材 |

## 评分体系

**德国**：1.0–4.0 及格，数字越小越好；1.0–1.5 sehr gut，1.6–2.5 gut，2.6–3.5 befriedigend，3.6–4.0 ausreichend；高于 4.0 不及格。部分成绩单同时给 ECTS 等级 A–E。

**中国成绩换算成德国分数**：常用"修正巴伐利亚公式"：

```
德国分数 = 1 + 3 × (满分 − 你的成绩) / (满分 − 及格线)
```

例如百分制、及格线 60、平均分 88：1 + 3 × (100 − 88) / (100 − 60) = 1.9。

- 用户的学校或 uni-assist 已经给过官方换算结果的，以官方为准。
- 自己换算的，网站上要注明"按修正巴伐利亚公式换算"。
- 用户不要求就不换算，直接展示原始成绩也可以（例如"GPA 3.6 / 4.0"）。

## 挑选相关课程

按目标岗位挑 4–8 门，标准：**和岗位相关** 且 **成绩不差**（德国 2.3 或更好，或者本校排名靠前）。课程名翻译成网站语言时，保留原名或附上原名，HR 有时会对照成绩单看。

## 深挖线索

- 毕业论文 → 问：解决了什么问题、用了什么方法、结论是什么、有没有和企业合作、有没有图表或代码可以展示。论文常常是学生最完整的"项目经历"。
- 项目课、研讨课成绩很好 → 问做了什么，能不能做成故事
- 成绩单显示的专业方向（Schwerpunkt、Vertiefung）和目标岗位的关系 → 用于定位语

## 网站用途

- 教育条目：学校、学位、时间、（用户同意的话）总成绩、相关课程
- 毕业论文 → 独立故事页
- 文件墙：成绩单默认"可按需提供"

## 敏感信息

成绩单上有学号或 Matrikelnummer、出生日期、出生地。原件默认不公开。**要不要在网站上写总成绩，一定问用户**：成绩好是加分项；成绩一般时不写也很正常，HR 需要时会单独要成绩单。
