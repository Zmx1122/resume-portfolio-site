# 推荐信（Empfehlungsschreiben / Referenzschreiben / Letter of Recommendation）

推荐信是**第三方对用户的具体评价**，比自我评价有说服力得多。它常出自教授、导师或前上司，里面经常有简历里没写的事例。

## 识别

- 抬头是推荐人的机构信纸，开头 `To whom it may concern` / `Sehr geehrte Damen und Herren`
- 正文讲推荐人和用户的关系、认识多久、具体事例、评价，结尾给出推荐强度（"without reservation""uneingeschränkt"）
- 中文推荐信多出自国内本科导师，常用于申请学校

## 提取

| 字段 | 说明 |
|---|---|
| 推荐人 | 姓名、职位、机构 |
| 关系 | 导师、上司、课程老师、项目合作者；认识多久 |
| 日期、用途 | 写给谁（某公司、某项目、通用） |
| 讲到的具体事例 | 逐条列出，标明对应哪段经历 |
| 评价的能力 | 逐条列出 |
| 推荐强度 | 原文措辞 |
| 可引用的句子 | 挑 1–2 句**最具体**的（讲了事例的句子比"TA很优秀"有用） |

## 深挖线索

- 推荐信里讲到的事例，简历里没有或只有一行 → 问用户要细节，挖成故事
- 推荐人提到的成果（论文、获奖、项目上线）→ 去资料池里找对应的材料互相印证

## 网站用途

- 推荐语版块或故事页的引用，署名格式："Prof. Dr. Anna Beispiel，TU München 某某教席，硕士论文导师"
- 事例 → 对应故事的素材

## 同意与公开

把推荐人的名字和评价放到公开网站上，最好先征得推荐人同意。采访时问用户一次："这封推荐信里的话，想引用到网站上吗？引用的话建议先跟推荐人打个招呼。"在 `content.js` 的引用条目里记录同意状态（见 `content-model.md`），状态不是"已同意"的引用默认不显示。

推荐信原件默认不公开：里面有推荐人的联系方式和签名，而且常常是写给特定机构的。

## 常见坑

- 中文推荐信要翻译时，保留推荐人的正式头衔，不要意译成更高的职位。
- 推荐信里有夸张的套话（"最优秀的学生之一"），引用时挑有事实支撑的句子。
