# 证书（语言证书 / 职业证书 / 课程证书）

证书是**最容易被验证的证据**。网站上给出验证链接，比 HR 自己去查方便得多，也显得专业。

## 分类

| 类别 | 例子 | 分量 |
|---|---|---|
| 语言证书 | Goethe-Zertifikat、TestDaF、DSH、telc、ÖSD、IELTS、TOEFL、Cambridge、DELF/DALF、JLPT | 高，德国求职常被要求 |
| 职业资格和厂商认证 | AWS、Azure、Google Cloud、SAP、Scrum（PSM）、PMP、ISTQB、CFA | 高，和岗位直接相关时 |
| 在线课程证书 | Coursera、edX、Udemy、LinkedIn Learning | 中低，选和岗位相关的展示 |
| 参加证明 | Teilnahmebescheinigung、参会证明、培训证明 | 低，放在次要位置或合并成一行 |

## 提取

| 字段 | 说明 |
|---|---|
| 名称 | 正式名称，包括级别（例如 Goethe-Zertifikat C1） |
| 颁发机构 | |
| 日期、有效期 | 有有效期的标出来（例如 IELTS、TOEFL 通常认 2 年） |
| 等级或分数 | 总分和分项分数都记下 |
| 证书编号或验证码 | 用于生成验证链接 |
| 验证链接 | Credly 徽章、厂商验证页、Coursera 证书链接；证书上有二维码就读出链接 |

## 语言等级换算

网站上的语言版块统一用欧标等级（A1–C2），HR 最容易看懂。换算只是**大致对应**，网站上写成"原始成绩 + 约等于的欧标等级"，不要只写换算后的等级：

| 证书 | 大致对应 |
|---|---|
| Goethe、telc、ÖSD | 证书本身就是欧标等级 |
| TestDaF | TDN 3 ≈ B2，TDN 4 ≈ B2–C1，TDN 5 ≈ C1 |
| DSH | DSH-1 ≈ B2，DSH-2 ≈ C1，DSH-3 ≈ C1–C2 |
| IELTS | 5.5–6.5 ≈ B2，7.0–8.0 ≈ C1，8.5 以上 ≈ C2 |
| TOEFL iBT | 72–94 ≈ B2，95–113 ≈ C1，114 以上 ≈ C2 |

例如："Deutsch — C1（TestDaF 4×TDN 4）"。没有证书的语言，用用户的自评，并在采访时问一句"平时用这门语言做什么"（比如"工作语言"、"日常交流"），这比等级更有说服力。

## 深挖线索

- 职业证书背后往往有学习项目或实际应用，问"考这个证之后用它做过什么"
- 证书等级和简历自评不一致 → 交叉比对的冲突
- 快过期或已过期的语言证书 → 问用户现在的实际水平

## 网站用途

- 证书墙：每张卡片写名称、机构、日期、等级，有验证链接就放"验证"按钮
- 语言版块：欧标等级 + 证书 + 实际使用场景
- 技能索引：职业证书作为相关技能的证据

## 敏感信息

语言证书上常有出生日期、出生地、照片、考生号。公开证书图片前，提醒用户遮住这些信息；更简单的做法是只放验证链接和文字信息，原件"可按需提供"。

证书在网站上默认"仅供查看"（`visibility: "preview"`）：`split_pdf.py` 加 `:preview` 和 `--watermark`，只放带水印的预览图，不放 PDF 原件，防止别人下载冒用。
