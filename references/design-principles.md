# 设计原则

一个求职网站好不好，首先看**HR 能不能在 30 秒内找到要的信息**，其次才是好不好看。这份文件讲怎么写设计说明、怎么让网站显得专业、以及哪些做法会让网站显得像"AI 随手生成的"。

部分思路参考了 Anthropic 开源的 frontend-design 技能（先确定明确的审美方向，再写代码），这里针对求职网站重新写过。

## 1. 先写设计说明

在做风格小样之前，写一份不超过 10 行的设计说明，给用户看一眼：

```markdown
**读者**：慕尼黑中小型制造企业的 HR 和数据团队负责人
**30 秒内要看到**：数据分析方向硕士在读，2027 年 4 月起可做 Werkstudent，德语 C1，做过三个部门在用的销售看板
**定位语**：我把销售和运营数据做成团队真正会用的看板和预测
**布局**：紧凑型（2 个故事）
**首页顺序**：精选故事 → 经历 → 技能 → 证书与文件 → 关于我
**语气**：克制、具体、可靠
**推荐风格**：瑞士极简 / 学术简约 / 温暖作品集
**语言**：德语（默认）、英语、中文
```

推荐风格时，说明为什么适合这个人。例如：瑞士极简清楚、有秩序，契合制造业 HR 的阅读习惯；温暖作品集更适合设计和传播方向。

## 2. 专业感从哪里来

- **信息有层次。** 读者扫一眼就能分出主次：姓名和定位语最显眼，其次是精选故事，再其次是细节。
- **每个说法都有证据。** 数字有来源，技能挂着故事，证书能验证。
- **一致。** 日期格式、大小写、标点、图片比例、按钮样式全站统一。不一致比不好看更伤可信度。
- **克制。** 一个强调色、两种字体、少量动效。
- **完整。** 没有占位文字，没有"即将上线"，没有坏链接，没有漏翻的句子。

## 3. 排版

- **最多两种字体**：一种用于标题，一种用于正文。也可以全站只用一种字体，靠字重和大小区分层次。
- **字号**：正文 16–18px，手机上不小于 16px。标题按比例放大（例如 1.25 倍一级），不要每级都随意定。
- **行宽**：正文每行 60–75 个西文字符（中文约 30–40 个字），太宽读起来累。
- **行高**：西文正文约 1.5–1.6，中文和日文约 1.7–1.8。
- **德语长词**：给 `<html>` 设置正确的 `lang` 属性，并开启 `hyphens: auto`，否则 "Datenanalyseprojekt" 这样的长词会撑破手机上的卡片。
- **数字**：表格和关键数字用等宽数字（`font-variant-numeric: tabular-nums`），对得齐。
- **字体文件放在本地**：模板默认用系统字体，不依赖外部服务。想换成特定字体（例如开源的 Inter、Source Serif），把字体文件放进 `assets/fonts/`，并确认字体许可证允许网页使用（SIL Open Font License 的字体都可以）。

## 4. 版式与间距

- **间距用 8 的倍数**（8、16、24、32、48、64）。所有间距来自同一组数值，页面才会显得有秩序。
- **先做手机版。** 很多 HR 是在手机上点开链接的。最窄按 360px 检查。
- **可点击的区域至少 44×44px**，手机上手指才点得准。
- **内容最大宽度**约 1100–1200px，正文栏约 680–720px。
- **对齐**：大部分内容左对齐（阿拉伯语等从右往左的语言是右对齐）。整页居中对齐只适合很短的内容。

## 5. 颜色

- 所有颜色用 CSS 变量定义（模板里叫 `--bg`、`--text`、`--accent` 等），风格只改变量。
- **一个强调色**，只用在链接、按钮和需要强调的少数地方。
- **对比度**：正文和背景的对比度至少 4.5:1（WCAG AA 标准）。浅灰字配白底是最常见的问题。
- **暗色模式**：模板会跟随系统设置，也提供切换按钮。每个风格都要给出暗色的变量，并且在暗色下检查一遍。

## 6. 图片

- **同一组图片用同一比例**（例如故事卡片都用 16:9 或 4:3），裁切时保留重点。
- **每张图都有说明文字和替代文字**（`alt`），每种语言都要有。
- **截图要脱敏**：真实客户名、同事姓名、内部数据先遮掉。
- **压缩**：宽度不超过 1600px，照片用 JPG（质量 80 左右）或 WebP，截图用 PNG 或 WebP。单张最好在 300KB 以内。
- **不用图库照片和 AI 生成的插画**冒充真实经历。没有图就不放，用排版撑起页面。

## 7. 动效

- 只在有意义的地方用：悬停反馈、页面切换、图片放大。
- 时长 150–250 毫秒，用缓出曲线。
- 尊重系统的"减少动态效果"设置（`prefers-reduced-motion`），模板已经处理。
- 不要自动轮播、视差滚动或打字机效果。HR 不会等。

## 8. 无障碍

模板已经处理了大部分，生成和修改时不要破坏：

- 用语义化标签：`header`、`nav`、`main`、`article`、`footer`，标题层级不跳级
- 所有功能都能用键盘操作，焦点清晰可见
- 图片放大窗口可以用 Esc 关闭、用方向键切换
- 每种语言的页面都设置正确的 `lang`，从右往左的语言设置 `dir="rtl"`

## 9. 让网站显得"AI 味"的做法

这些做法很常见，但会让网站显得像模板随手生成的，HR 一眼就能看出来。避免：

- 技能进度条和百分比（"Python 90%"）：没有意义，也没有依据
- 紫蓝渐变背景、霓虹光晕、满屏毛玻璃效果
- 首页一行大字"Hi, I'm …" 加挥手表情
- 三个并排的图标卡片写"创新""协作""热情"
- 图库照片、AI 生成的人物插画
- 所有东西都居中、都加阴影、都加圆角
- 打字机动画、自动轮播、滚动时到处飞入的元素
- 空洞的形容词："passionate""results-driven""detail-oriented"
- 每个版块标题前都加一个装饰图标

一个检验办法：把姓名换成别人，网站是否照样成立？如果是，说明它还没有体现这个人。

## 10. 发布前的细节

这些细节决定网站"像不像认真做的"：

- **网页标题和描述**：在 `index.html` 里填好默认语言的 `<title>` 和 `<meta name="description">`
- **分享预览**：填好 `og:title`、`og:description`、`og:image`（建议 1200×630 的图，可以是姓名加定位语的简洁图片）。把链接发到 LinkedIn、邮件、微信时，显示的就是这些内容。这些标签要写在 HTML 里，不能只靠 JavaScript 生成，因为抓取预览的程序通常不运行 JavaScript
- **网站图标**：用姓名首字母做一个简单的图标（`assets/favicon.svg`）
- **打印**：速览页可以直接打印成一页简历
- **404**：网址里的故事 id 写错时，显示友好的提示和返回首页的链接（模板已处理）
