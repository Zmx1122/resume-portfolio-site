# 暗色科技（terminal-dark）

**一句话**：默认深色，标题、标签、导航用等宽字体，绿色强调，版块标题前有 `$ `，技能标签前有 `#`。一看就是写代码的人。

**适合**：软件开发、数据工程、机器学习工程、安全、DevOps、嵌入式方向；读者是技术团队负责人。

**不太适合**：非技术岗位，或者读者是传统行业 HR（深色页面在这类 HR 眼里可能不够"正式"）。

## 视觉要点

- 字体：标题和小标签用等宽字体（SF Mono / Menlo / Consolas），正文用无衬线体保证可读性
- 颜色：近黑绿底 `#0c0f0b`，浅灰绿字，强调色绿 `#4ade80`
- **默认就是深色**，不跟随系统的浅色模式；用户点切换按钮时，换成一套"纸面终端"浅色配色（米白底、深绿强调）
- 装饰（都很克制）：品牌名前 `~/`，姓名后一个绿色 `_`，版块标题前 `$ `，标签前 `// `，技能前 `#`
- 时间线分隔线用虚线
- 圆角很小（4px）

## 内容上的配合

- 故事里写清技术栈和具体做法，技能标签多一些也没关系
- 有 GitHub 链接一定放上
- 不要再额外加打字机动画、代码雨之类的效果（见 `design-principles.md` 第 9 节）
