# 风格总览

模板内置 6 个风格。风格只决定外观（颜色、字体、版式细节），**不改变内容和结构**，所以随时可以换。每个风格的样式文件在 `assets/template/assets/styles/<风格 id>.css`，说明文件在本目录。

| 风格 id | 名称 | 一句话 | 适合 |
|---|---|---|---|
| `swiss-minimal` | 瑞士极简 | 黑白、粗线、强网格、一个红色 | 工程、数据、咨询、制造业，德国中小企业 |
| `editorial` | 报纸编辑风 | 衬线、报头、分栏细线，像一份报纸 | 经历丰富、爱讲故事；产品、咨询、媒体 |
| `bento` | Bento 卡片 | 圆角色块拼成网格，第一个故事占大格 | 产品、市场、设计、偏视觉的项目 |
| `terminal-dark` | 暗色科技 | 默认深色、等宽字体、绿色 | 软件开发、数据工程、安全、DevOps |
| `warm-portfolio` | 温暖作品集 | 米色纸感、衬线标题、大图、陶土色 | 设计、传播、教育、人文社科 |
| `academic` | 学术简约 | 窄栏、衬线正文、蓝色链接、几乎无装饰 | 读博、科研岗、研究型实习 |

## 怎么推荐

1. **先看读者，再看用户喜好。** 读者是德国传统行业的 HR，优先推荐瑞士极简或学术简约；读者是创业公司或设计团队，可以推荐 Bento 或温暖作品集。
2. **看内容。** 图片多，选 Bento 或温暖作品集；文字故事多，选报纸编辑风；论文和发表多，选学术简约。
3. **每次推荐 3 个**，其中至少一个是"稳妥"选项（瑞士极简或学术简约），并说明每个的理由。
4. 用户在采访模块 F 里说过喜欢的感觉或网站，优先匹配。

## 怎么做小样

用户的内容放进 `site/` 之后，用同一份内容生成三个预览文件，让用户双击打开对比：

1. 复制 `site/index.html` 三次，分别命名为 `preview-1.html`、`preview-2.html`、`preview-3.html`（放在 `site/` 里，和 `index.html` 同一层）。
2. 在每个文件里，把 `id="style-css"` 那一行的风格文件名换成要预览的风格，例如 `assets/styles/editorial.css`。
3. 告诉用户三个文件的完整位置和对应的风格名称，请TA双击打开，看首页和一个故事页，回一个编号。能运行命令的话，用 `node scripts/screenshot.js 我的简历网站/site --file preview-1.html --pages "de/"`（`--file` 换成每个预览文件）截图，直接发三张截图更省事。
4. 用户选定后，**删掉三个预览文件**（它们不应该被发布），按 `components.md` 第 5 节把风格写进 `index.html` 和 `content.js`。

不要让用户自己在网址后面加参数（`?style=`），这对非技术用户太难。用户说"你定"或"跳过"，就用第一推荐。

聊天模式下没法生成预览文件，用文字描述三种风格的样子，请用户选一个，或者用第一推荐。

## 用户想要微调

常见的微调只改风格文件开头的变量：

| 想改 | 变量 |
|---|---|
| 强调色 | `--accent`（按钮、重点），`--link`（链接） |
| 背景和文字颜色 | `--bg`、`--surface`、`--text`、`--muted`、`--line` |
| 字体 | `--font-head`（标题）、`--font-body`（正文） |
| 圆角 | `--radius`、`--radius-small` |

每个风格都有浅色和深色两套变量，改的时候两套都要改，并检查对比度（正文至少 4.5:1）。

## 用户想要一个全新的风格

复制最接近的那个风格文件，改名（例如 `my-style.css`），然后修改变量和少量规则。新风格名也要加进 `assets/app.js` 开头的 `STYLES` 列表，`?style=` 预览才能识别它。
